📄 Pages & Blocks
Pages are the foundation of Notion — they can be simple notes, home dashboards, meeting notes, wiki articles, or full database entries. Pages can also contain subpages, enabling nested structures for teams, departments, or projects. ALM Corp
Blocks are the individual pieces of content inside a page — paragraphs, headings (H1–H4), lists, images, toggles, code snippets, embeds, and callouts are all blocks. The block-based editor lets you drag, rearrange, and convert block types freely. ALM Corp
Specific block types include:

Text, headings (H1–H4), bullet lists, numbered lists, to-do checklists
Toggle lists (collapsible sections)
Callout blocks
Quotes, dividers, columns
Code blocks
Images, videos, audio files
File attachments and PDFs
Embeds (YouTube, Figma, Google Maps, etc.)
Synced Blocks
Tabs — let you split a page into clean sections to keep related content together without a long vertical scroll (type /tabs to get started) Notion
Buttons — automate block creation, database entries, page generation, and property edits with a single click Notion
Synced Blocks — edit content once and changes propagate everywhere it appears Notion


🗄️ Databases
A Notion database is a structured collection of entries where each entry is its own full page. Databases can power task trackers, CRMs, editorial calendars, pipelines, inventories, and many other systems. ALM Corp
Database Views:
Table, Board (Kanban), List, Calendar, Timeline (Gantt), Gallery, and Chart views let you look at the same underlying data in different ways. ALM Corp

Dashboard view — a new view type that aggregates data from linked databases into cards, charts, and metric tiles (shows computed summaries, not individual rows) Fazm

Database Properties:
Properties are the fields attached to database items — they can store status, date, priority, assignee, tags, URLs, numbers, formulas, and relations to other databases. ALM Corp The full list includes: Text, Number, Select, Multi-select, Status, Date, Person, File & Media, Checkbox, URL, Email, Phone, Formula, Relation, Rollup, Created time, Created by, Last edited time, Last edited by, ID, and Verification (wiki-only).
Database Features:

Filters, sorting, and grouping
Linked database views (view same DB in multiple places)
Database templates (pre-fill new entries)
Relations between databases
Rollups (aggregate related data)
Sub-items and dependencies
Smart filters (relative dates, "assigned to me")


📚 Wikis
Wikis are pages that can be turned into collaborative knowledge bases. They include a Home view (freeform blocks), an All Pages view, and a Pages I Own view. You can create additional views with layouts like calendar, timeline, or list. Notion
Wikis come with four default properties: Owner, Last edited date, Tags, and a Verification property. The Verification property lets you mark documents with an expiration date and get notified when it's time to review them. Notion
